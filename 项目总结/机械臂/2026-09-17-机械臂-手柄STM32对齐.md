## 2. 操作映射（STM32 对齐）

### 底盘（麦克纳姆）

| 摇杆 | 作用 |
|------|------|
| 左 X | 原地转 `angular.z` |
| 左 Y | 前后 `linear.x` |
| 右 X | 左右平移 `linear.y` |
| 右 Y | 前后（与左 Y 叠加） |

### 机械臂（按住连续动，松开自然停）

| 按键 | 关节 |
|------|------|
| 方向左右 | joint1 |
| 方向上下 | joint2（大臂） |
| △ / ✕ | joint3 |
| ○ / □ | joint4 |
| L1 / R1 | joint5 |
| L2 / R2 | 夹爪（看 `axes`，不是 buttons） |
| SELECT / START | 急停底盘+停臂（对齐 `$DJR!`，不再跑 init） |

## 3. 当前调参（文件顶部）

| 参数 | 当前值 | 说明 |
|------|--------|------|
| `JOINT_SPEED` | 12 | 臂匀速峰值 |
| `GRIPPER_SPEED` | 18 | 夹爪速度 |
| `JOINT_ACCEL` | 3 | 臂加速度（每周期速度变化上限） |
| `GRIPPER_ACCEL` | 4 | 夹爪加速度 |
| `ARM_CMD_PERIOD` | 0.04 | 25Hz |
| `SERVO_DURATION` | 0.05 | 单步插补 |
| `LOCK_PUBLISH` | False | 松手不额外硬锁位（防回调抖） |
| `joint2` 限位 | **10 ~ 650** | 大臂软限位（联调定稿） |
| `HOME_POSITION` | j2=750 等 | 内存初值；动之前会跟 `servo_states` 对齐 |

## 4. 关键实现要点（踩坑）

1. **首动猛抽**：内存 HOME 与实车位不一致 → 开转前 `sync` 自 `servo_states`。  
2. **停后回调劲大 / 抖**：松手若用**滞后反馈**回拉，会反向猛抽 → **不要**停时 `sync_from_fb` 再发锁位；`LOCK_PUBLISH=False`。  
3. **太肉**：不要靠把 `JOINT_SPEED` 砍半；应 **速度不变、降 `JOINT_ACCEL`**。  
4. **重启节点**：需 `OPENBLAS_CORETYPE=ARMV8`，否则 exit -4；`pkill -f joystick` 易误杀上传 shell，用 `[j]oystick_control.py` 或分步重启。  
5. **车上 IP 会变**：改 `tools/06_deploy/upload_to_car.ini` 的 `host`（该文件已 gitignore）。
