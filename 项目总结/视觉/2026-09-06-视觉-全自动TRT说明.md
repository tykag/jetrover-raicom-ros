# 2026-09-06 视觉全自动 TRT 说明

目标：分拣区自动锁定「左→园区一、右→园区二」；待派送区自动识别 bolt/gear 再抓取。
CPU ONNX ~3.7s/帧不够用，必须上 **TensorRT**。

## 1. 电脑导出 320 ONNX（更快）

```cmd
D:\yolo_env\venv\Scripts\activate.bat
cd /d D:\yolov5
python export.py --weights runs\train\raicom_bolt_gear3\weights\best_fixed.pt --include onnx --img 320 --device cpu --opset 12
```

把生成的 onnx 改名为 `best_fixed_320.onnx`，传到小车：

```text
/home/hiwonder/yolo_models/best_fixed_320.onnx
```

同时传：`raicom_yolo_trt.py`

## 2. 小车生成 TensorRT engine（只做一次，可能要几分钟）

```bash
sudo nvpmodel -m 0
sudo jetson_clocks
ls /usr/src/tensorrt/bin/trtexec
/usr/src/tensorrt/bin/trtexec \
  --onnx=/home/hiwonder/yolo_models/best_fixed_320.onnx \
  --saveEngine=/home/hiwonder/yolo_models/best_fixed_320.engine \
  --fp16
```

成功后有：`~/yolo_models/best_fixed_320.engine`

## 3. 全自动连续检测

```bash
sed -i 's/\r$//' ~/yolo_models/raicom_yolo_trt.py
source ~/ros_ws/devel/setup.zsh
export ROS_MASTER_URI=http://127.0.0.1:11311
export ROS_IP=127.0.0.1
unset ROS_HOSTNAME
python3 ~/yolo_models/raicom_yolo_trt.py
```

看日志里的 `xxms`：目标大约 **30～100ms** 量级（视板子型号而定）。  
连续 3 次左右结果一致后会打印 `MAPPING LOCKED`，并写入：

- 文件：`~/yolo_models/last_mapping.txt`
- 话题：`/raicom/mapping`、`/raicom/mapping_ready`
- 参数：`/raicom/p1_class`、`/raicom/p2_class`

## 4. 全自动程序怎么用

状态机示例：

1. 导航到智能分拣区，A 右转 / B 左转，正对标识板  
2. 启动/等待 `mapping_ready==true`  
3. 读 `p1_class` / `p2_class`（gear 或 bolt）  
4. 去待派送区：YOLO 检出货物类别，查映射决定送园区一还是二  
5. 深度相机取抓取点 → 臂运动抓取放置  

待派送抓取可复用同一 engine；后续再加深度取点与臂控制节点。

## 5. 依赖

小车需有：`tensorrt`、`pycuda`（厂方 YOLO 示例一般已带）。  
若 `import pycuda` 失败：`pip3 install pycuda --user`（Jetson 上有时需按官方方式装）。
