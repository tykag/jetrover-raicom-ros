## 2. 赛题与视觉需求（智械争锋）

| 区域 | 视觉任务 | 判定规则 |
|------|----------|----------|
| **智能分拣区** | 识别板上 bolt / gear | 正对板后：画面**左→园区一(P1)**，**右→园区二(P2)** |
| **A/B 半场** | 抽签决定 | A：往待派送方向开时分拣区在**右手**，臂转 90° 看板；B：在**左手**。**看清板后左右含义相同** |
| **待派送区** | 识别货物类别并抓取 | 查映射：该类 → P1 或 P2，再导航放置 |
| 控制要求 | **全自动** | 不能依赖空格等人操作 |

货物：蓝色块、齿轮、T 型螺栓等约 5cm；标识为白块上印刷图案。

## 4. 视觉链路（已完成）

```text
小车采图 → 电脑 LabelImg 标注 → YOLOv5 训练
→ best.pt 类别名对调 → best_fixed.pt
→ 导出 ONNX (opset 12, img 320)
→ 小车 trtexec → best_fixed_320.engine (~19ms)
→ raicom_yolo_trt.py 连续检测 → MAPPING LOCKED
```

### 4.1 电脑侧路径

| 内容 | 路径 |
|------|------|
| 训练环境 | `D:\yolo_env\venv`（Python 3.11） |
| YOLOv5 | `D:\yolov5` |
| 数据 | `D:\yolo_data\`（images/labels + `raicom.yaml`） |
| 权重 | `D:\yolov5\runs\train\raicom_bolt_gear3\weights\best.pt` |
| 名称修正后 | `...\best_fixed.pt`（0=gear, 1=bolt） |
| 导出 | `best_fixed_320.onnx`（opset≤12，适配车上旧 onnxruntime） |

类别最终约定（`best_fixed` / TRT）：

```text
0 → gear
1 → bolt
```

训练时曾把 LabelImg 默认类表标成 15/16，已批量改成 0/1；名称一度反了，用 `fix_yolo_names.py` 对调进 `best_fixed.pt`。

### 4.2 小车侧路径

| 内容 | 路径 |
|------|------|
| 模型目录 | `/home/hiwonder/yolo_models/` |
| Engine | `~/yolo_models/best_fixed_320.engine` |
| ONNX 备份 | `~/yolo_models/best_fixed_320.onnx` |
| 检测脚本 | `~/yolo_models/raicom_yolo_trt.py` |
| 映射结果 | `~/yolo_models/last_mapping.txt` |
| ROS 参数 | `/raicom/mapping_ready`、`/raicom/p1_class`、`/raicom/p2_class` |
| 话题 | `/raicom/mapping`、`/raicom/mapping_ready` |

生成 engine（车上，只需一次）：

```bash
/usr/src/tensorrt/bin/trtexec \
  --onnx=$HOME/yolo_models/best_fixed_320.onnx \
  --saveEngine=$HOME/yolo_models/best_fixed_320.engine \
  --fp16 --workspace=2048
```

**注意：`.engine` 必须在小车上生成，不能在 Windows 电脑转好再拷。**

### 4.3 映射逻辑（代码）

```text
检出 ≥2 个目标 → 按框中心 cx 排序
更左 → P1（园区一），更右 → P2（园区二）
连续稳定若干次 → MAPPING LOCKED，写文件/参数
```

### 4.4 看板动作组（不转底盘）

相机在臂上：A 半场转 joint1 看右手分拣板，看完转回正前方抓待派送。

| 动作组 | 含义 | joint1 |
|--------|------|--------|
| `look_board` | 右转约 90° 看板 | 875 |
| `look_front` | 平放向前抓取 | 500 |
| `look_board_b` | 左转约 90°（B 半场） | 125 |

其余关节固定：`750, 0, 375, 500`，夹爪 `500`。脚本：`tools/04_vision_car/raicom_arm_pose.py`。

## 6. 当前推荐启动方式（不改自启期间）

自启曾出现 **崩溃循环**（约 8s 退出再重启）。调视觉时：

```bash
sudo systemctl stop start_app_node.service
```

**终端 A – bringup（保持开着）：**

```bash
source ~/ros_ws/devel/setup.zsh
export ROS_MASTER_URI=http://192.168.10.110:11311
export ROS_IP=192.168.10.110
unset ROS_HOSTNAME
roslaunch hiwonder_bringup bringup.launch
```

**终端 B – 视觉：**

```bash
source ~/ros_ws/devel/setup.zsh
export ROS_MASTER_URI=http://192.168.10.110:11311
export ROS_IP=192.168.10.110
unset ROS_HOSTNAME
python3 ~/yolo_models/raicom_yolo_trt.py
```

实验室当前 IP 多为 `192.168.10.110`；若 `hostname -I` 不同，两处 export 改成实际 IP。

日志里 `校验失败`（串口 CRC）、语音 `构建语法失败`、缺相机标定 yaml：**调检测可先忽略**。

## 7. 网络 / 比赛热点（待办，视觉后再改）

| 场景 | 做法 |
|------|------|
| 实验室 | 现多用固定 `192.168.10.110` |
| 比赛手机热点 | IP 会变 → 需 `ROS_IP=$(hostname -I \| awk '{print $1}')` |
| 自启 | 最终应改为启动时自动取 IP（**先不做**） |

原则：终端与 master **地址必须一致**；不要混用 `127.0.0.1` 与 `192.168.10.110`。
