## 3. 启动（反复用的只走这些）

```bash
~/start_raicom_auto.sh                 # 整栈：全向 + 双地图 + 手柄 + RViz + YOLO + 状态机
roslaunch raicom nodes.launch          # 导航已在跑，只补 YOLO/状态机

rosservice call /raicom/look_cargo
rosservice call /raicom/status
rosservice call /raicom/test_pick      # 新 pick 和 pick_aim 都标完才能用
rosservice call /raicom/abort
rostopic pub -1 /raicom/save_pose std_msgs/String "data: pick"
```

同一件事做了第二次，升成 launch 参数或服务，不要再写 `_ssh_*.py`。

## 4. 抓放技术路线

1. YOLO 认货，底盘把目标对到 `pick_aim`（图像伺服）。
2. 示教姿势抓/放；深度只做滤目标、估远近、分高低、抓后确认。
3. 园区：`park*_approach` → 低速 creep → 作业位。不要把 `park1`/`park2` 直接当全局导航终点。
4. `grasp_mode:=3d` 默认关。手眼残差 ≤5 mm 且散布不大之后，才拿三维去够更远、更歪的块。
5. `allow_high:=false`，直到 `place_down_high` 实车示教。

当前卡点：新 `pick`、新 `pick_aim` 未标定；车充电后必须重新 2D Pose Estimate。
