# 2026-09-19 待派送抓放：你要怎么做

台上按实拍摆：**2×2 四摞、每摞两层、共 8 块**。齿轮/螺栓哪摞都可以换。  
调爪子时可以先只留 **靠车最近的一摞**，调完再摆回 8 块。  
车从黄台空着的那一边正对台子。不要 `rosservice call /raicom/start`，那是最后一步。

完整代码就这 4 个文件（本机 → 小车 `~/yolo_models/`）：

```text
tools/04_vision_car/raicom_arm.py
tools/04_vision_car/raicom_auto.py
tools/04_vision_car/raicom_yolo_trt.py
tools/04_vision_car/raicom_arm_poses.yaml
```

---

## 第 0 步：拷到小车

WinSCP 覆盖上面 4 个到 `~/yolo_models/` 后：

```bash
sed -i 's/\r$//' ~/yolo_models/raicom_arm.py ~/yolo_models/raicom_auto.py ~/yolo_models/raicom_yolo_trt.py
chmod +x ~/yolo_models/raicom_*.py
```

---

## 第 1 步：开车（3 个终端）

每个终端都先贴：

```bash
source ~/ros_ws/devel/setup.zsh
export ROS_MASTER_URI=http://127.0.0.1:11311
export ROS_IP=127.0.0.1
unset ROS_HOSTNAME
export OPENBLAS_CORETYPE=ARMV8
```

**终端 A**

```bash
sudo systemctl stop start_app_node.service
roslaunch hiwonder_navigation navigation.launch map:=explore
```

电脑 RViz 里 **2D Pose Estimate** 对墙。有 master 时禁止再 `roscore`。不要关 WiFi。

**终端 B**（等导航起来约 10 秒）

```bash
python3 ~/yolo_models/raicom_yolo_trt.py
```

**终端 C**

```bash
python3 ~/yolo_models/raicom_auto.py
```

**终端 D（手柄）** 必须在 A 已经有 master 之后再开，否则会 `auto-starting new master`、手柄废：

```bash
roslaunch hiwonder_peripherals joystick_control.launch
```

---

## 第 2 步：示教「能夹住」（台上只留一摞）

1. 手柄把车开到待派送空边，正对台子。  
2. 只留靠车最近的一摞（上层那块对着相机）。  
3. 另开终端 E（同样 source + 四个 export）：

```bash
python3 ~/yolo_models/raicom_arm.py look_front
rosparam set /raicom/yolo_mode detect
```

4. 夹爪张开。手柄挪底盘和臂，直到这块货就在爪子正前方、伸下去能夹住。  
5. 停在「货上方、爪开」：

```bash
python3 ~/yolo_models/raicom_arm.py save pick_hover
```

6. 再落到「能夹住、爪仍开」：

```bash
python3 ~/yolo_models/raicom_arm.py save pick_down
```

7. 此时画面里必须还能看到这块货：

```bash
python3 ~/yolo_models/raicom_arm.py save_aim
```

应打印 `SAVED pick_aim ...`。

8. **不要碰手柄**，试手臂动作（车不动）：

```bash
python3 ~/yolo_models/raicom_arm.py pick
```

夹住了就对。夹爪张合反了：改 `~/yolo_models/raicom_arm_poses.yaml` 里 250 和 750 对调，再 `pick` 一次。

---

## 第 3 步：换个位置，试底盘自己对

把这一摞挪到台上另一格（或左右移 10cm）。手离开手柄。

```bash
rosservice call /raicom/test_pick
```

车应自己平移/前后，对到刚才 `save_aim` 的画面位置，再抓。  
乱冲：`rosservice call /raicom/abort`。  
左右走反：yaml 里 `pick_aim` 的 `y_sign` 改成 `-1`。  
前后走反：`x_sign` 改成 `-1`。  
`test_pick` 会杀掉手柄节点，还要掰臂就再开一次终端 D。

这一步过了，随机摆放才有用。不过先别摆满 8 块。

---

## 第 4 步：第二层高度

把上层拿走，只留下层那块，再手柄落到能夹：

```bash
python3 ~/yolo_models/raicom_arm.py save pick_down_low
python3 ~/yolo_models/raicom_arm.py pick_low
```

---

## 第 5 步：园区放置（仍是示教，台子位置固定）

手柄开到园区一，爪子还夹着货，放到台面上：

```bash
python3 ~/yolo_models/raicom_arm.py save place_down_low
python3 ~/yolo_models/raicom_arm.py place_low
```

叠第二层再：

```bash
python3 ~/yolo_models/raicom_arm.py save place_down_high
python3 ~/yolo_models/raicom_arm.py place_high
```

---

## 第 6 步：台上摆回 8 块，全自动

黄台：**四摞 × 两层**。车回起点，Pose Estimate 再对一次墙。

```bash
rosservice call /raicom/start
```

急停：`rosservice call /raicom/abort`。

它会：分拣板锁 P1/P2 → 去待派送 → 每次盯一块、对位、抓 → 按类别送园区 → 低/高交替放。前 4 次用 `pick_down`（上层），后 4 次用 `pick_down_low`（下层）。

今天如果第 3 步还没稳，停在第 3 步，不要做第 6 步。
