## 3. 明天接着做

1. 停自启，开 `navigation.launch map:=explore`，RViz **2D Pose Estimate** 对墙。  
2. 再开 `python3 ~/yolo_models/raicom_auto.py`（存点、启动都靠它）。  
3. 手柄另开 `roslaunch hiwonder_peripherals joystick_control.launch`。必须先有导航 master，否则会 `auto-starting new master`，手柄控不了。  
4. 在外列对一块货，示教后试抓：

```bash
python3 ~/yolo_models/raicom_arm.py save pick_hover
python3 ~/yolo_models/raicom_arm.py save pick_down
python3 ~/yolo_models/raicom_arm.py pick
```

5. 到园区示教 `place_down_low`，必要时 `place_down_high`。夹爪反了就对调 yaml 里 250 / 750。  
6. 抓放稳了再：`rosservice call /raicom/start`（会杀掉手柄自己开）。急停：`rosservice call /raicom/abort`。

每个新终端：

```bash
source ~/ros_ws/devel/setup.zsh
export ROS_MASTER_URI=http://127.0.0.1:11311
export ROS_IP=127.0.0.1
unset ROS_HOSTNAME
export OPENBLAS_CORETYPE=ARMV8
```

有 master 时禁止再 `roscore`。`python3` 不要 `import tf`（Melodic 是 py2）。
