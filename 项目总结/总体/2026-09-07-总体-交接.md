## 3. 开机自启（已修好）

服务：`start_app_node.service` → `wait_rrc.bash` → `source_env.bash` → `bringup.launch`。

**真正死因：** systemd 自启只 source 了 `.typerc`，**没有**终端里 `.hiwonderrc` 的 `OPENBLAS_CORETYPE=ARMV8` 和 `LD_PRELOAD=libgomp`。numpy/OpenBLAS 在 Jetson 上探测 CPU 会 **SIGILL（exit -4）**。`ros_robot_controller` / `hiwonder_servo_manager` 都是这个，节点 `required` → 整场退出。不是语音、不是 WiFi、不是 udev 笔误。

**已上车（2026-09-07 18:01，NRestarts=0，电池话题 10644 mV）：**

- `source_env.bash`：`OPENBLAS_CORETYPE=ARMV8` + `libgomp` preload；`ROS_IP=127.0.0.1`；`unset ROS_HOSTNAME`
- 服务：等 `/dev/rrc` 且 `hw_button_scan` 先起来；日志进 journal
- **没关** WiFi / ModemManager / 语音，**没改** `required`

厂方 `hw_button_scan.service` 会一直占着 `/dev/rrc`，这是出厂设计，不要杀。udev `"1"1"` 笔误车上已改成 `"1"`。

连 ROS：

```bash
source ~/ros_ws/devel/setup.zsh
export ROS_MASTER_URI=http://127.0.0.1:11311
export ROS_IP=127.0.0.1
unset ROS_HOSTNAME
rostopic list
```

重做补丁：`tools/01_startup/apply_autostart_b.sh`（不要跑旧的 `fix_autostart.sh`）。

**已否决：** 关 WiFi；为保自启注释语音；关 ModemManager；把 `required` 改成 `respawn` 当治本；跑 `fix_autostart.sh`。
