或一条龙（无导航、停在分拣区）：

```bash

# 再:

```

A 半场默认；B 半场：`SIDE=B SKIP_NAV=1 ~/start_raicom_auto.sh mapping_only`

## 3. 全流程（要导航）

1. 停自启，起导航 + 状态机：`~/start_raicom_auto.sh`  
2. RViz **2D Pose Estimate** 对墙。  
3. 用手把车开到各点（可临时再起手柄，或先示教再全自动）存路点：

```bash
rostopic pub -1 /raicom/save_pose std_msgs/String "data: sort"
rostopic pub -1 /raicom/save_pose std_msgs/String "data: pick"
rostopic pub -1 /raicom/save_pose std_msgs/String "data: park1"
rostopic pub -1 /raicom/save_pose std_msgs/String "data: park2"
```

可选第二摞：`park1_b` / `park2_b`。写入 `~/yolo_models/raicom_waypoints.yaml`。

4. 车回起点，Pose Estimate 再对一次。  
5. `rosservice call /raicom/start`  
6. 急停：`rosservice call /raicom/abort`

循环 8 次：待派送识别 bolt/gear → 查 P1/P2 → 抓 → 对应园区 → 低/高交替放。
